# FRD-09 — Settings and theme

**Source:** 2026-11-22: *"customize the theme. have a settings cog in upper left that when clicked opens a full screen modal with left bar (settings screens) and main panel… First option is theme. Color wheel on left with list of colors on right (color chip and input box with hex value) clicking color modifier will change color wheel to that option. you can drag to change, change happens live. If you cancel out changes are not saved and if you click save & confirm changes are saved. Also provide a dropdown… presets… all the dracula alts… Blade Buffy Morbius Helsing"*

| ID | Priority | Requirement | Verification | Status |
| --- | --- | --- | --- | --- |
| SET-01 | Must | A gear button in the bottom-left corner of the sidebar opens Settings. When the sidebar is hidden, it is reachable from the hover preview of the sidebar. | Manual: gear visible bottom left with the sidebar pinned, and in the hover preview when hidden. | Implemented |
| SET-02 | Must | Settings fills the window: a page list on the left (Theme is the first page) and the selected page on the right, with **Cancel** and **Save & Confirm** at the bottom. It replaces the workspace while open, so the terminal can't receive keystrokes meant for Settings. **Escape** cancels. | Manual: layout at 1120×720 and 820×440; Escape closes it. | Implemented |
| SET-03 | Must | The Theme page lists the eleven Dracula palette colors (Background, Current Line, Foreground, Comment, Cyan, Green, Orange, Pink, Purple, Red, Yellow), each with a color chip and a hex field. Clicking a color moves the color wheel to it. | `selecting_a_color_moves_the_wheel_to_it` | Implemented |
| SET-04 | Must | Dragging on the color wheel sets hue (angle) and saturation (distance from the center). A brightness slider sets value. Only the selected color changes. The drag keeps tracking outside the wheel, clamped to its rim. | `dragging_the_wheel_and_brightness_recolor_only_the_selected_slot_live`, `wheel_positions_map_to_hue_and_saturation_and_clamp_to_the_rim` | Implemented |
| SET-05 | Must | Hex fields accept `#RRGGBB` or `#RGB`. A valid code applies immediately. Partial input is kept while typing and reset to the real value when another color is selected. | `typing_a_hex_code_applies_once_valid_and_keeps_partial_input`, `hex_codes_parse_in_long_and_short_forms_and_reject_anything_else` | Implemented |
| SET-06 | Must | Every edit previews live across the whole app (window, panels, text, icons and built-in widgets). **Cancel** restores the saved theme; nothing is written. | `theme_edits_preview_live_and_cancel_restores_the_saved_theme` | Implemented |
| SET-07 | Must | **Save & Confirm** writes the palette atomically to `~/Library/Application Support/Worktree Browser/theme.json` and applies it. The saved theme loads at launch. A missing file means Dracula, and colors missing from the file fall back to Dracula. An unreadable file shows a notice and uses Dracula. | `saved_theme_applies_and_survives_a_restart`, `saved_theme_round_trips_and_missing_file_means_dracula`, `theme_file_with_a_bad_color_is_an_error_but_missing_colors_use_dracula` | Implemented |
| SET-08 | Must | If saving fails, the error appears in the notice bar and Settings stays open with the edits intact. | `failed_theme_save_keeps_the_modal_open_and_shows_the_error` | Implemented |
| SET-09 | Should | A **Preset** dropdown replaces every color with a built-in palette: Dracula, Alucard (light), Dracula Pro, and the Pro variants Blade, Buffy, Lincoln, Morbius and Van Helsing. It shows the matching preset, or **Custom** once any color differs. | `presets_replace_every_color_and_edits_show_as_custom`, `presets_are_recognized_only_when_every_color_matches` | Implemented |
| SET-10 | Must | The theme covers the app's own chrome only. The embedded terminal keeps the user's Alacritty colors (CFG-*), and the Alacritty config is never written. | `styles_follow_the_palette_they_are_given`; Manual: terminal colors unchanged after switching presets. | Implemented |
